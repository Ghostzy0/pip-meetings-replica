# Contributing

Use a focused branch/PR and a reproducible synthetic case. Run scripts/test-native.sh and build both editions before changing their acceptance claims. Changes to recording, async cancellation, recovery, egress, permissions or exports require targeted regression coverage. Keep participant consent and content boundaries explicit. Preserve upstream/licence notices and exact dependency pins.

Do not commit audio from real meetings, personal screenshots, accounts/tokens, model caches or generated build products. Report only tests you actually ran. Keep known native/platform gaps visible. Public issues and PRs must not contain private data.
