# Foundation and editions

Native source is based on [Meeting Transcriber0.8.1](https://github.com/pasrom/meeting-transcriber/tree/a4f6af6df2674bc4e18097084a128af469823fab), exact revision a4f6af6df2674bc4e18097084a128af469823fab, MIT copyright2025 pasrom. The entire usable native capture/recovery/transcription architecture is retained. Original licence and dependency texts remain in native/LICENSE, native/THIRD-PARTY-NOTICES.md and native/licenses/. Modified Pip additions are independently authored; no reserved-rights Pip-motion code or Granola assets are included.

Neutral and Pip products share PIP_EDITION: the original local workspace plus hard boundaries excluding upstream external providers, auto-watch, updater and debug/automation routes. PIP_NEUTRAL selects native system appearance and a separate identity. Enhanced neutral/Pip builds enable the same small MEETINGS_ENHANCEMENTS feature after baseline validation. A separate upstream provenance build disables product conditions and retains the foundation behaviour with isolated data. Upstream releases/maintainer are not the Pip distributor. Inspect source/CHANGELOG for exact modifications. All four product variants need their own build and runtime acceptance.

[oats](https://github.com/ariso-ai/oats/tree/79c3bbead82ddc9bb901828d51372a8dc2c3dc87), MIT, was evaluated but not imported. [Granola](https://docs.granola.ai/help-center/taking-notes/transcription) is the recognisable functional reference; it requires SSO/native grants for hands-on workflow comparison. Official documentation is labelled documented behaviour, not observed parity. Pip deliberately retains local source audio; Granola's stated audio policy differs.

The app licence is not an umbrella weight licence. LocalVQE echo resource is Apache2 and hash-pinned. WhisperKit/FluidAudio and their dependencies keep individual notices. Additional downloaded Whisper tiny.en CoreML/tokenizer files are pinned separately in docs/speech-assets.json; exact MIT/Apache2 provenance is in docs/LOCAL-SPEECH.md. No speech weights or raw reference screenshots are source Git files.
