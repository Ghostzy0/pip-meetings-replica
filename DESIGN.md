# Native presentation

The neutral and Pip products share one local recorder/library/action core. Neutral selects native system surfaces, accent and symbols. Pip uses an original paper/ink interface and independently drawn still character. No proprietary reference assets or reserved motion library are included.

Pip uses a white/light paper canvas or near-black dark canvas, quiet grey secondary surfaces/selections, ink primary actions and a system text family. Spacing uses4/8/12/16/24/32points; the sidebar is280points and long reading content is constrained. Native text editors, menus and file panels retain familiar Mac behaviour. Colour supplements explicit status words.

The character is a new decorative drawing, hidden from accessibility. Idle UI has no repeating animation. Avoid invented processing progress and respect Reduce Motion. Reference functionality is Granola; original appearance and participant/source boundaries remain independent.

Neutral Core's `MEETINGS_REPLICA` view is selected only by the `baseline` build. The 23 October signed-in demo showed a wide centered home card, then a narrow note with a system-serif title, plain editor, local metadata, bottom recording dock, and rounded lower transcript drawer. The adapter uses native system colors and type; it does not include vendor artwork, fonts, code, calendar entries or cloud-enhanced text. Local calendar availability is stated in place. Cloud assistant actions are omitted rather than presented as working controls. `baseline-enhanced`, `pip`, and `pip-enhanced` remain on the custom workspace.

The detail view responds down to480pt and its bottom transcript drawer can be closed or reopened. Its movement is suppressed when Reduce Motion is active. Editor input is held in the local durable draft store until the user saves; recognized source passages remain separate from edited transcript text. The compiled render, keyboard/focus, light/dark and reduced-motion paths still need runtime verification.

Actual native rendering, keyboard/focus, minimum size and accessibility acceptance are tracked in PUBLIC-VERIFICATION.md. Source design choices do not establish runtime quality.
