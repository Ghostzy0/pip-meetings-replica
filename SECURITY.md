# Security and privacy reports

Never put private audio, transcripts, screenshots, access tokens or account data into a public issue. Report a minimal synthetic reproduction. Use the repository's available private reporting route when configured; otherwise open a non-sensitive issue asking for a private contact method. No response-time commitment is made.

Pip is an experimental native app. Local files are not application-encrypted. Operating-system permissions, disk protection and participant consent remain necessary. Source/build verification does not prove complete capture, network, sandbox or accessibility acceptance. Neutral and Pip product builds share explicit local-only boundaries; the separately named upstream provenance mode retains upstream features. Neither uses another application's session credentials.
