# Move permitted meeting material

Keep originals and export a copy from your existing service using its supported controls. Meetings Replica does not access another application's private store, account session or credentials.

For audio you have permission to process, use the local Import audio workflow after preparing the pinned speech resources. Review the resulting transcript. Copy your own notes manually and add actions/decisions with the appropriate source link, or leave a manual note clearly unlinked. Source text and user edits are distinct.

Reopen the saved meeting, inspect source references and test an export before removing anything from the previous service. Proprietary projects, automatic Granola sync, calendars, invitations and task-manager integrations are not implemented. This migration route is experimental; see [actual verification](../PUBLIC-VERIFICATION.md) for the paths tested in the current build.
